# New York City Food Landscape Analysis

**Author:** Mitchell Fields  
**Focus:** Exploratory Data Analysis (EDA), Data Visualization, Urban Food Systems  

## 🧭 Overview
This project explores the food landscape of New York City through a data-driven lens, highlighting both strengths and challenges within the city’s diverse food environment. Using exploratory analysis and interactive visualizations, the project examines patterns related to food availability, quality, and accessibility across different areas and categories.

The analysis emphasizes clear visual communication and insight generation for both technical and non-technical audiences.

## 📊 Tableau Dashboard & Presentation
All exploratory analysis and visual exploration for this project were conducted using **Tableau**. Key findings and visual insights are summarized in a presentation-style format designed to communicate results clearly to stakeholders.

The Tableau work includes:
- Exploration of dataset structure and key variables
- Visual analysis of distributions and category-level patterns
- Identification of strengths and challenges within the NYC food landscape
- High-level interpretations supported by interactive and static visuals

## 🔍 Analysis Performed
- Performed exploratory data analysis entirely within Tableau.
- Created dashboards to examine patterns and relationships across food-related variables.
- Used visual filtering and comparisons to highlight disparities and trends.
- Translated exploratory findings into a presentation-friendly narrative.

## 🧰 Tools Used
- **Tableau:** data exploration, dashboard creation, and visual analysis  
- **PowerPoint / PDF:** presentation of findings  
- **Git / GitHub:** documentation and version control  

## 🧠 Key Insights
- New York City exhibits a wide and diverse food landscape, with noticeable variation across categories and locations.
- Visual patterns suggest differences in access and quality that may impact consumer choice and public health outcomes.
- Tableau dashboards enable intuitive exploration of trends and highlight areas for deeper analysis.
